# Kernel research

This directory is reserved for DroidiOSXNU's original XNU integration notes and patches.

No XNU source has been vendored here yet. The project should pin an exact public source revision, preserve its license and notices, and document every local change as a patch. Do not copy another project's implementation wholesale.

Initial tasks:

- identify a public XNU revision relevant to the research target;
- review its license and build documentation;
- record supported architectures and platform assumptions;
- establish a reproducible host-side build before device-specific work.
