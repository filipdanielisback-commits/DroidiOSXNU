# IPSW research

This directory is for documentation and metadata-oriented tooling only.

An IPSW is a firmware package, not iOS source code. The project may reference public firmware catalogs such as [IPSW.me](https://ipsw.me/), but it will not store or redistribute IPSW files, extracted proprietary binaries, keys, certificates, or personal device data.

Keep local firmware outside the repository. Any future tool must have a clearly documented, lawful purpose and must not bypass security controls.
